What is real in this prototype
The classifier, the pause decision and the complaint writer run in your browser. Bangla and Banglish input is understood the same way the production model is designed to work: intent, not a word list.
What is simulated
Number reputation, live call audio, USSD and in-app triggers, the agent-shop feed and Scam Radar records are demo data. Those are the parts that need Grameenphone's network and an MFS partner.
Product rules this demo keeps
Warn, never block. Quiet when nothing is wrong. One question at a time. Nothing recorded, nothing uploaded. The user always keeps the last button.
